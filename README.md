# JDNEXT UI — Static Prototype

Ein eigenständiger, statischer Web-UI-Prototyp, der sich am allgemeinen Aufbau des neueren Just-Dance-Menüs orientiert: linke Icon-Leiste, Featured-Banner, Playlist-Kacheln und Song-Reihe.

## Status

- **Nur Oberfläche:** keine Navigation, Songauswahl, Anmeldung, API oder Spiellogik.
- **Eigene Platzhaltergrafiken:** Karten und Figuren werden mit CSS gestaltet; keine Original-Songcover, Coaches oder sonstigen Spieldateien enthalten.
- **Keine Build-Tools nötig:** `index.html` direkt im Browser öffnen.
- **Responsive:** passt sich an kleinere Bildschirme an.

## Lokal starten

`index.html` öffnen oder GitHub Pages unter **Settings → Pages** auf den `main`-Branch und das Verzeichnis `/ (root)` einstellen.

## Dateien

- `index.html` — Struktur des Menüs
- `styles.css` — Layout, Farben, Effekte und CSS-Platzhaltergrafiken
- `.nojekyll` — GitHub-Pages-Hinweis

Fan-/Konzeptprojekt, nicht offiziell und nicht mit Ubisoft verbunden. Eigenständige Annäherung an den allgemeinen UI-Stil; keine pixelgenaue Kopie offizieller Spieldateien.
